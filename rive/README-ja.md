## 名前と型(`rive inspect` で確認)
Artboard `Rikyu`(500×500、背景なし) / State Machine `Main`(デフォルト)

| Input | 型 | 内容 |
|---|---|---|
| `mood` | Number | 0=ふつう、1=うれしい、2=応援、3=集中、4=お茶を飲む(しぐさをくり返す。追加) |
| `isTalking` | Boolean | true の間、口の開閉と体・顔の小さな揺れ |
| `bow` | Trigger | 1.5秒のおじぎ |
| `wave` | Trigger | 1.6秒の手ふり |
| `whisk` | Trigger | 0.33秒の茶せん |
| `cheer` | Trigger | 1.2秒のうなずき(2回) |
| `levelUp` | Trigger | 1.9秒。扇子を開き、葉が3枚舞う |

レイヤーは Breath(呼吸・まばたき)/ Mood(表情)/ Speech(会話)/ Gestures(しぐさ)の4つで独立。会話としぐさは同時に動きます。Idle は6秒のループで、最初と最後のコマが同じ値なのでつなぎ目がありません。表情の切り替えは 0.25 秒。

## 色
抹茶 #5C7838、焦茶 #2B1F17、白 #FAF9F5、灰 #78736E、肌色 #F5E3CC の5色だけ。ほおの赤みは入れていません。グラデーション・影・光沢なし。まゆは白だと肌と見分けにくいので、灰色にしました。

## 確かめていないこと
- iPhone アプリ(Rive iOS Runtime)での読み込みと再生。組み込むときに確認が必要です
- プレビューの窓で、動きを通しで見ること(コマごとの描画だけ確認)。動きのなめらかさは、窓で一度見てください: `rive outputs/rikyu-source`
- しぐさの途中で別のしぐさを呼んだときのつながり(AnyState)は、作りの上では対応していますが、描画で確かめたのは茶せんの連打だけです
- PNG は RML の形から SVG を作って書き出したもので、Rive の描画そのものではありません(Rive の画面キャプチャは背景が付くため)。見た目は `qa/` の Rive の描画と同じ形です
