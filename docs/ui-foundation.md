# ui-foundation.md — アプリ基盤の UI/UX 方針(Mobbin 調査)

テーマ・案に依存しない「基盤」の設計方針。CLAUDE.md のデザイン原則と人間工学的指針を、具体的な画面の作法に落としたもの。
案が決まったら、この方針で共通部品(`DesignSystem/`)を作り、各画面はそれを組み合わせて作る。

## 2. 画面の骨格(全画面共通)

```
+---------------------------+
| ナビゲーションバー           |  表示だけ(タイトル・状態)。頻繁に押すボタンは置かない
|                           |
| 大見出しは控えめ(.title2)    |
| 内容(リスト / 主役の表示1つ)  |  区切り線と余白で階層を作る。カードを敷き詰めない
|                           |
|                           |
|      [ 主要操作ボタン ]      |  親指の届く下部。1画面に主要操作は1つ
+---------------------------+
```

- 1画面に主役は1つ(大きな数字・1枚の画像・1つのリストのどれか)。
- 主要操作は画面下部に1つだけ(幅いっぱいのボタン、または右下の丸ボタン)。高さ 50pt 以上。
- 詳細は push かシートで1段深く。深さは3階層まで。
- シートは必ずスワイプと右上の閉じるボタンの両方で閉じられる。処理中も閉じられる。
- 確認ダイアログは削除などの破壊的操作だけ。それ以外は「元に戻す」で取り返せるようにする。

## 3. 共通部品(`DesignSystem/` に作るもの)

| 部品 | 中身 | 守る原則 |
|---|---|---|
| `Theme` | 色(背景・文字・区切り線・アクセント1色・朱色)、余白(4 / 8 / 16 / 24)、角丸、文字スタイル | 一貫性。色に意味を持たせる |
| `PrimaryButton` | 下部固定の主要操作ボタン。押した瞬間に縮む動き+ハプティクス | アフォーダンス / 44pt 以上 |
| `SectionHeader` | 小さめの見出し+細い区切り線(Things 3 風) | 明瞭性 |
| `CloseButton` | シート右上の閉じるボタン(丸いグレー地に x) | 脱出性 |
| `StatusLabel` | 状態をアイコン+文字+色の3点で示すラベル | 色だけに頼らない |
| `EmptyState` | 空のときの案内文と、最初の1歩のボタン | 明瞭性 / デモで空画面を見せない |
| `Haptics` | 成功・選択・警告の触覚をまとめた関数 | 節目のフィードバック |
| `Stamp`(案次第) | 朱色の判子を図形で描く部品 | 絵文字を使わず図形で描く |

## 4. 実装の約束

- 絵文字は使わない。絵は SwiftUI の図形で描く。アイコンは SF Symbols(保留: 自作にするかはデザイン担当と相談)。
- 影・グラデーション・自作のガラス表現を使わない。OS 標準部品のガラス表現はそのまま。
- Dynamic Type に対応する(固定の文字サイズを使わない)。
- 主要な操作は VoiceOver で読める名前を付ける。
