## 案3「おとなの舌」子ども向けの詳細(例)
- 文字を読ませない。記録は表情アイコン3つ(苦い / ふつう / おいしい)を押すだけ。表情は絵文字を使わず SwiftUI の図形で描く(口の曲線で表情を変える)。
- 挑戦するだけで舌レベルが上がる(おいしく感じなくてもよい)。「克服」ではなく「挑戦した自分がかっこいい」。
- 機能: (1)ひとくち記録 (2)レベルアップの演出(「舌レベル」が上がる)(朱色の判子 + 触覚) (3)水墨画風タイルの挑戦記録
- MVP: 撮る → 表情を選ぶ → 舌レベルが上がる演出
- デモ: 審査員に「ゴーヤが苦手な子ども」役でゴーヤチップスを食べてもらい、苦い顔を押しても舌レベルが上がり判子が押される

## 案6「ほしいも」(試作済み 2026-10-24)
- 名前: ほしいも = 干し芋 + 「欲しいも(の)」。サブタイトル「その欲しいも、干してから。」
- 衝動買い防止。欲しい物をすぐ買わずに軒下へ吊るし、干す長さ(1分 / 3日 / 7日 / 30日)が過ぎて「食べごろ」になったら「買う / 見送る」を決める。見送った金額が「浮いたお金」として貯まる。
- 干し芋が基本。吊るすときに干し柿も選べる(渋柿は干すと甘くなる = テーマ「渋い」とのつながり)。
- 絵は図形で描く: 干し芋は 紫の生芋 → 黄色の蒸し芋 → 飴色+白い粉、干し柿は 青い渋柿 → 橙 → 茶色+しわ。
- ウィジェット: 浮いたお金と次の食べごろ。食べごろがあればタップで決める画面へ。
- 過去の SPAJAM 最優秀賞の傾向: 千秋楽(2025本選。大相撲×会場を巻き込むプレゼン)、MoT〜灯達を供養して〜(2024予選。独自の世界観とデザイン)。和の言葉+独自の世界観+会場参加型のデモが強い。
